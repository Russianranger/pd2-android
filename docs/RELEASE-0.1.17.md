# 0.1.17 HID read-cancellation experiment

The 0.1.16 physical result **accepts full Stop/Play within the same Android app process** and still rejects Native after Save/Quit. Both fresh controller identity operations completed in Wine but failed to restore gameplay. [Controller census](evidence/2026-10-06-controller-census.md) establishes one accepted Android pad and one live Wine HID parent; Wine's visible and hidden child interfaces represent the same controller. Independent HID and legacy UDP XInput paths remain, without evidence of a second physical pad overriding the first.

This preview adds **Launch settings → Controller → Save/Quit experiment → HID read cancellation fix (experimental)**. It defaults Off. The accepted Wine 9.2 HIDclass driver has the exact inverted early-cancellation condition corrected by upstream Wine. The opt-in applies that one instruction correction to the verified matching 64-bit driver and updates its PE checksum; all other bytes remain identical. Controller mappings, descriptor, XInput DLLs and session cleanup are unchanged. This is a new handle/read-lifecycle hypothesis, not another focus or device reconnect trial. Physical Save/Quit recovery remains unproven.

The driver changes only after successful full private-session cleanup, before Windows startup. Exact original and patched hashes, bounded staging, verified original backup and atomic replacement protect installation and rollback. Unknown drivers are preserved and reported as launch failures; an active patch requires its verified original backup. An unused invalid backup does not block the original driver while Off. Off restores the verified original on the next clean Play. No prefix, imported game, save or registry file is changed by this experiment.

Support logs add bounded controller slot counts and declared Windows client PID/port categories. These can reveal multiple legacy consumers in a later capture; they do not authenticate Linux socket ownership or prove simultaneous connected controllers. Input values are not logged.

Version 0.1.17/code 18 preserves Wine 9.2 Custom, Box64 0.4.4, rootfs 24, application/signing identity, relocated assets, graphics/GameNative arguments, Stability, current HID producer, prefix/import/saves, accepted LT/thumb/shoulder/Menu/cursor behavior and container protections. Install over the existing app; **no Prepare runtime or re-import**. Follow [Testing](TESTING.md) and export the failed state before Stop.
